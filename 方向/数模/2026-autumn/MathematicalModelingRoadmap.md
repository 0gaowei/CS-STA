# 数模入门指南（2026 秋）

> 负责人：Zheng Zhihang（[GitHub](https://github.com/Ther-zh)）

这份指南写给想打数模、但还不知道从哪下手的同学，说一下今年大概怎么安排。

先看时间线。数模校赛在下个学期，到时候会组织大家参加，校赛同时也是国赛的选拔。国赛一般在暑假，赛前会有培训，培训主要是跟队友协作做三道题，做完有导师点评，还有相关课程可以关注。数模的比赛基本都集中在下个学期，所以这学期有一整个学期的时间，先把基础打好，不用急，但也别闲着。

这学期主要做三件事：

第一，学好高数。这是基础。数模里的建模、推导、优化，底层都是高数，还有线代和概率统计。数学课认真上、课后题动手做，比急着看一堆模型教程有用得多。

第二，想提前了解数模的话，可以去 B 站找"数模加油站"这个 UP 主，跟着先把基础模型过一遍。评价类、预测类、优化类、图论这些，先有个印象，知道什么样的题大概用什么模型就行，不用一上来就抠细节。

第三，今年和往年最大的区别，就是 Agent 出来了。他拿来打数模还是很好用的。建议大家去了解、学会市面上主流的 Harness 框架，特别是把 skill 是什么搞清楚，然后去看看市面上有哪些数模 skill，试着搭一个自己的数模 skill（具体可以看 Agent 组的学习材料），把自己学过的模型慢慢攒成知识库。这个越早开始越好。

组队是按三个方向分工的，大家想想自己想往哪边靠：

编程手，负责把模型变成能跑的代码。Python 和 MATLAB 至少熟练一个，平时多练数据处理和画图，论文里的图基本就看编程手了。建议把自己常用的代码攒成一个"武器库"，比赛的时候直接拿来改。

建模手，负责读题、把实际问题变成模型，选模型、推公式。模型原理要吃透，不能只会调包，灵敏度分析、误差分析这些也要会，论文里的模型检验部分要你来把关。平时多读历年国赛的优秀论文，看看别人是怎么把题拆成模型的。

论文手，整篇论文都归你管：摘要、公式、图表、参考文献，最后交到评委手里的是你的作品。建议去了解一下 LaTeX，学会用 Overleaf 跟队友协作，几个人同时写也不容易乱。还有两点：论文不是把编程手的结果复制粘贴，结果要自己解释、做误差分析；模型也不是越复杂越好，符合题意、讲得清楚才拿分。

另外，不管做哪个方向，都建议大家学会用 GitHub 协作，熟悉一下基本流程（仓库、分支、提交、PR）。这个不只是数模用得上，以后做项目、打别的比赛都用得上。组里的资料后面也会陆续传到仓库里。
